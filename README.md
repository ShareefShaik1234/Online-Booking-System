# 🚀 Reservix – Online Booking System

Reservix is a **full-stack online booking system** designed to provide a simple and convenient platform for managing multiple types of bookings in one place.

Users can register, log in, search available services, make bookings, view their bookings, and manage their reservations through a user-friendly web interface.

> **Reservix — Book Everything in One Place.** 🎟️

---

## ✨ Features

* 🔐 User Registration & Login
* 🎬 Movie Booking
* 🚌 Bus Booking
* 🚆 Train Booking
* 🏨 Hotel Booking
* 🔎 Search available services
* 📋 View booking history
* 🗑️ Delete bookings
* 🌙 Light/Dark Mode
* 👨‍💼 Admin Dashboard
* 🔒 Login protection for booking pages
* ☁️ Frontend and Backend deployment

---

## 🎬 Movie Booking

Users can browse and search for movies and make reservations by providing the required booking details.

---

## 🚌 Bus Booking

Users can search for buses based on **source and destination**, select an available bus, and make a reservation.

---

## 🚆 Train Booking

Users can search for trains based on **source and destination** and book tickets by selecting:

* Journey date
* Coach
* Number of seats

---

## 🏨 Hotel Booking

Users can search for hotels based on **city** and make hotel reservations through the booking interface.

---

## 🔐 Authentication

Reservix provides:

* User registration
* User login
* Login protection for booking pages
* Session state using browser local storage

Users must log in before accessing the booking services.

---

## 👨‍💼 Admin

The project also includes an admin section for managing the booking system through an admin dashboard.
